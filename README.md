# 📸 パシャ領収書

**「リンクをもらう → 撮る → しゃべる → 送る」だけ**の、いちばんシンプルな領収書アプリです。
アプリのインストール、アカウント作成、カテゴリの選択はいりません。

## 使う人（お客さん）の流れ

1. 税理士さんから届いたリンクを開く（初回だけ。送信先は自動で登録されます）
2. **📷 撮影する** → 領収書を撮る
3. 撮るとそのまま音声入力が始まるので「コンビニで文房具 1200円」としゃべる
4. **✅ 送る** → おわり（すぐ次の1枚を撮れます）

- 金額は話した言葉から自動で読み取ります（「1200円」「千二百円」「1万2000円」など）
- 電波が悪いときは端末に保存して、つながったときに自動で再送します
- 音声入力に対応していないブラウザでは、キーボードのマイクボタンで入力できます
- ホーム画面に追加すると、アプリのように使えます

## 受け取る人（税理士さん）の準備 ― 1回だけ・約5分

1. Google スプレッドシートを新しく作る
2. 「拡張機能」→「Apps Script」を開き、[`gas/Code.gs`](gas/Code.gs) の中身を貼り付けて保存
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 出てきた `https://script.google.com/macros/s/…/exec` をコピー
5. お客さんにこのリンクを送る：

   ```
   https://airrich1.github.io/receipt-app/?to=<4のURL>
   ```

届いた領収書は、シート「領収書」に `受信日時 / 名前 / 金額 / メモ / 写真リンク / 仕訳済☑` の形で1行ずつ増えます。
写真はスプレッドシートと同じ場所の「領収書写真」フォルダに入ります。
お客さんごとにシートを分けたい場合は、お客さんごとに 1〜4 を行ってください。

## アプリの公開について

カメラとマイクを使うため、**HTTPS で公開する必要があります**。
このリポジトリは GitHub Pages で公開します（Settings → Pages → Branch: main / root）。
公開URL：https://airrich1.github.io/receipt-app/

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（1ファイル完結・外部ライブラリなし） |
| `manifest.json` | ホーム画面に追加するための設定 |
| `gas/Code.gs` | 受け取り側（スプレッドシートに貼る Apps Script） |

## 注意

- 「アクセスできるユーザー：全員」にすると、URL を知っている人は誰でも送信できます。URL はお客さん以外に共有しないでください。
- このアプリは領収書の写真とメモを集めるだけです。電子帳簿保存法の要件を満たすかどうかは、運用方法（タイムスタンプ・検索要件など）とあわせて税理士さんにご確認ください。
